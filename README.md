# 📚 Data Structures Using Java Generics

## 📖 Project Overview

This repository contains the implementation of fundamental **Data Structures** using **Core Java** and **Java Generics**. The project is designed to build a strong understanding of how commonly used data structures work internally instead of relying on Java's built-in collection classes.

Each data structure is implemented from scratch using Object-Oriented Programming (OOP) principles and Java Generics, making the implementation reusable for different data types.

The project follows a use case–based development approach where every feature is implemented and tested incrementally.

---

# 🎯 Project Objectives

- Learn how data structures work internally.
- Implement Linked List without using Java Collections.
- Understand Java Generics for reusable code.
- Build Stack using Linked List.
- Build Queue using Linked List.
- Implement Hash Table using Linked List.
- Implement Binary Search Tree (BST).
- Improve problem-solving skills.
- Practice clean code and object-oriented programming.
